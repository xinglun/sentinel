# 🐕 Stock Sentinel 戦略設計哲学と評価

本ドキュメントでは、Stock Sentinel（意思決定レーダー）のコアとなる設計思想について説明します。本システムは複雑なテクニカル指標を排除し、「大道至簡（究極のシンプルさ）」の原則に基づき、**「飼い主 (Owner) - リード (Leash) - 犬 (Dog)」** のメタファーを中心に構築された、哲学的思考と実践的な防御力を兼ね備えた準工業的な指標システムです（総合評価：95/100）。

## 1. コア設計哲学：大道至簡 (究極のシンプルさ)

ノイズと非合理的な熱狂に満ちた金融市場（「敏感なウサギのような相場」）において、短期的な急騰や暴落によって方向性を見失うことは容易です。本システムは、物理的な距離の入れ子関係を通じて、トレンドとボラティリティを具体化します：

* **飼い主 (Owner)**: 長期トレンド（例：MA200やMA120）を表します。飼い主の進行方向（上山または下山）が戦略の基調を決定します。
* **リード (Leash)**: 中短期トレンドの平均（例：MA20）を表します。リードの長さは、システムが許容できるボラティリティの限界を示します。
* **犬 (Dog)**: 現在の市場価格を表します。犬は常に活発に動き回るため、犬の毎日の動きに基づいて意思決定を行うと、終わりのない往復ビンタ（Whipsaw）に陥ります。

**システムの本質**: 私たちは「犬」がコースから外れているかを直接観察するのではなく、「リード」が引っ張られているかを観察し、「飼い主」の大きな方向性と組み合わせて、定量的な操作指示（積み立て、買い増し、または完全な防御）を策定します。

## 2. 三位一体のバランス次元 (The Balance)

このシステムは、**「感情管理（高値掴み防止）+ 平均回帰（パニック売り防止）+ トレンドフォロー（落ちるナイフ掴み防止）」**を見事に融合しています：

### 次元1：右側トレンドフォロー（落ちるナイフを回避）
真の弱気相場において、単なる「押し目買い (Buy the dip)」は悲惨な結果を招きます。
* **ルールの実装**: **ベアモード (Bear Mode)** を導入。「飼い主（長期MA）」が下山を始めた場合、システムは強制的にダウングレードをトリガーします。このとき、以下の2つの状態に分かれます：
  * **CAUTION (警戒モード)**: 短期的な調整中であり、ポジションを構築するための積み立ての継続を許可します。
  * **DEFEND (防御モード)**: トレンドの崩壊が確認された場合、買い推奨を強制的に剥奪し、現金保有比率（Cash %）を最大まで引き上げて、素手で落ちるナイフを掴むのを防ぎます。

### 次元2：往復ビンタ防止のための平滑化メカニズム (Anti-Whipsaw via Leash Cross)
ボラティリティの高い市場では、「犬（価格）」が頻繁に警戒線を越え、システムに誤ったシグナルを発生させます。
* **ルールの実装**: 深度防御（DEFEND）に入るかどうかを判断する際、「犬（価格）」を見るのではなく、**「リード（MA20）」**が長期MAを割り込んだかを見ます。リードが切れていない限り、システムは一時的なダマシ（假摔）によってポジションを手放すことはありません。これにより、敏感な市場でのノイズが大幅に平滑化されます。

### 次元3：左側平均回帰と構造的健康診断（安全なパニック時の免除権）
従来の移動平均線戦略の最大の弱点は「遅行性」です。ブラックスワンによる暴落に直面した場合、システムはしばしば大底で「売り/防御」シグナルを発し、暴落を回避できないだけでなく、その後のV字回復（深V反発）を逃してしまいます。一方で、無目的に「落ちるナイフ」を掴むことも危険です。
* **ルールの実装**: **MA200 ゴールキーパー (MA200 Goalkeeper) と 極端なパニック時の免除権 (Extreme Fear Exemption)** を導入。「飼い主」が下山しているかどうかにかかわらず、「犬」が驚いて猛ダッシュし、「リード」を物理的限界まで引っ張った場合（ `fear` 閾値をトリガーした場合）、システムはまず**構造的な健康診断**を行います。逆張り（抄底）を許可するためには、以下の**3つの条件をすべて満たす**必要があります：
  1. **偏差の極端化**: 乖離率が設定されたパニック閾値（fear）に達していること。
  2. **陣地の死守**: 価格（またはリード）が確実に長期MA（MA200）の上にあること。
  3. **大局の安定**: 長期MA（MA200）自体のトレンドが「下降（Down）」ではないこと。

これらを満たす場合のみ、強気相場（指数牛市）の中の「黄金の落とし穴」と見なし、免除権を与えて全力買いを指示します。
もし条件のいずれかが欠けている場合（例：価格がMA200を下回っている、またはMA200自体が下落している）、それは構造的な崩壊（長期的な衰退トレンド）と見なされます。この場合、システムは免除権を冷酷に剥奪し、強制的に防御状態（`fear_downtrend` / DEFEND）へと移行し、「落ちるナイフ」を掴むのを防ぎます。

## 3. 限界のエッジケース (Edge Cases)

システムの究極の安定性は、極めて稀な相場を完璧に捉えることを放棄することと引き換えに得られています。使用時には以下のシナリオに注意する必要があります：

1. **長期的な「真綿で首を絞めるような」下落 (Slow Bleed)**：
   市場が急騰や暴落をせず、毎日1%ずつ下落し、それが3ヶ月続く場合。このような陰跌は「乖離率」の瞬間的な拡大による極端なパニック状態を引き起こしにくいため、（免除権をトリガーできません）。最終的には「リードの割り込み（Leash Cross）」によって認識され、長い防御期に入ります。結果的に損切りには成功するものの、その過程は忍耐を試されるものになります。
2. **単日の極端な反転 (Flash Crash & Recovery)**：
   本レーダーは日足レベル（Daily Close）のデータに基づいて動作します。もし日中に20%暴落し、その後すぐに急反発するような神がかった相場が発生した場合、市場の終了後にはシステムから正確な「パニック買い」の指示が出ますが、翌日の開場時には価格が既に手の届かないところまで跳ね上がっている可能性が高いです。

## 4. 結論と実践的意義

現在のアーキテクチャは主観的な判断を排除し、すべての Action 返却内容が、明確な**現金保有比率の提案**（例：`Cash 10%`、`Cash 80%+` など）として設定されています。

この「大道至簡」の設計を堅持し、`config.toml` に設定されたデータの規律と組み合わせることで、本システムは米国株におけるボラティリティの高い長距離走において、短期的な感情のノイズを遮断し、純粋なルールの利益を獲得するのに役立ちます。

## 5. Parameter Sweep 科研プロセス (v1.0.0 封存後)
システムは v1.0.0 でアーキテクチャとして完成（封存）しています。今後、異なる市場環境に適合させるためのパラメータチューニング（Parameter Sweep）を行う場合は、システムを「フランケンシュタイン化」させないため、以下の厳格な科研プロセスに従う必要があります。

**1. ターゲット関数は「単一の数字」ではなく「パレート最適（Pareto Front）」であること**
* 以下の4つの指標をバランスよく追求します。どれか1つを極端に最適化するとシステムは崩壊します。
    * Trend Calibration Error（下がるほど良い）
    * Trend Alpha（高置信度の期待リターン、上がるほど良い）
    * Reversion Alpha（低置信度の反発リターン、上がるほど良い）
    * CAPITAL STATE Transition 安定性（日々のアウトプットが過度に振動しないこと）

**2. 局所的なスイープから始める（全宇宙検索の禁止）**
* 影響が大きい以下の3つの「物理的な意味を持つノブ」を優先し、一度に1つずつチューニングします：
    * `owner_ma_days` (例：60 / 120 / 150 / 200)
    * `buffer_pct` などの閾値 (例：2 / 3 / 4)
    * `confirm_days` / 確信度閾値 (例：[5/3], [7/4], [10/5])

**3. OOS (Out-Of-Sample) 検証の分割**
* データを「訓練（Train: 例 2015-2020）」と「検証（Validate: 例 2020-2025）」に厳密に分けます。Train 期間で最適に見えたパラメータが Validate 期間で機能しない場合、それは「物理法則」ではなく単なる「ノイズへの過学習」とみなされ、破棄されます。

**4. 3つの「性格の異なる」パレート最適解を導出する**
* ただ1つの「最強パラメータ」を選ぶのではなく、「保守的（低ボラティリティ）」「バランス（総合最適）」「攻撃的（強いReversion）」の3セットの最適解を見つけ、マクロの `CAPITAL STATE` に応じて使い分けることを推奨します。
