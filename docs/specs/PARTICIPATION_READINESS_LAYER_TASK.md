# 参加準備レイヤーの履歴メモ

この文書は履歴メモであり、現行の実装要件ではありません。

現行の事実 SSOT は `trend_cohesion` と `trend_gate_changed` です。
旧参加準備という語義は、設計検討の痕跡としてのみ残してあります。

後続の仕様や実装では、旧参加準備を current SSOT として扱わず、
`trend_cohesion` 系の現在の契約を参照してください。
