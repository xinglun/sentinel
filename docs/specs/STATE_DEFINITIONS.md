# Sentinel 状態定義マニュアル (STATE_DEFINITIONS.md)

## 1. 市場状態 (Market Regime)

市場状態は最高レベルの意思決定フィルターであり、ポートフォリオレベルのリスクエクスポージャーの上限とアクションの傾向を決定します。

### 1.1 メイン状態の定義

| 状態名 | コアセマンティクス | 許可されるアクション | 禁止されるアクション |
| --- | --- | --- | --- |
| `IGNITION` | トレンドの萌芽、ボラティリティが非常に高い | 極小量の打診買い (Pilot) | 大口の追撃買い |
| `NEWBORN` | トレンド確立の初期段階、まだ不安定 | 分割買い（建玉開始） | 全力での加筆 |
| `EARLY_CONFIRMATION` | トレンドが最初の押し目確認を通過 | 標準的な加筆 | なし |
| `ESTABLISHED` | 強気トレンドの中後期、高い安定性 | 保持、順張りでの追加買い | 激進的なポジション反転 |
| `CONFIRMED` | トレンドが極めて成熟、過熱リスクを伴う | ポジション縮小、買い停止 | 新規エクスポージャーの追加 |
| `DEFENSIVE` | 構造が破壊され、防御モードに移行 | 強制清算、大幅なバランスシート縮小 | 押し目買い、ナンピン |

### 1.2 内部の2層属性

より精緻なロジックを実現するため、内部では2層の表現を採用しています：

*   **Lifecycle State**: `IGNITION` -> `NEWBORN` -> `EARLY_CONFIRMATION` -> `ESTABLISHED` -> `CONFIRMED`
*   **Risk Overlay**:
    *   `NORMAL`: リスク管理下、計画通りに実行。
    *   `DECELERATING`: モメンタムの減衰、追加買い頻度の抑制。
    *   `DEFENSIVE`: 構造的損傷、防御的な売却または凍結を実行。
    *   `BROKEN`: トレンドが完全に終結。

## 2. 個別銘柄の状態 (Asset State)

個別銘柄の状態は、引力中心（Owner MA）に対する相対的な位置と特徴に基づいて決定されます。

| 状態名 | セマンティック記述 | 典型的な特徴 |
| --- | --- | --- |
| `OPTIMAL` | 最適な保持期間 | 引力帯の上方にあり、トレンドの傾斜が上向き |
| `CRUISE` | 安定巡航期 | 引力帯をわずかに上回り、低ボラティリティ |
| `PULLBACK` | 健全な押し目 | 引力中心付近まで下落、構造は未破壊 |
| `CAUTION` | 警戒期 | 重要なサポートを割り込むが、全面防御には至らず |
| `OVERHEAT` | 極度な過熱 | 引力帯から 2σ 以上乖離、いつ大幅修正が起きてもおかしくない |
| `DEFEND` | 防御モード | 構造的な節目を割り込み、ポジション縮小が必須 |
| `FORMING` | 構造形成中 | 履歴データ不足、または引力構造が混乱 |

---

## 3. 状態のマッピング関係

*   **対外的な表示**: 最終的にユーザーに表示されるのは、組み合わせ後の単一の状態です（例: `ESTABLISHED (Decelerating)`）。
*   **アクションの駆動**: アクションは `(Market Regime, Asset State)` で構成されるマトリックスによって一意に決定されます。
