# Template Glossary

| 用語 | 定義 |
|---|---|
| Preflight Review | 実装前に Contract evidence から readiness を表示するレビュー。 |
| Preflight Pause Rule | review が `needs_human_confirmation` または `not_ready` のとき、実装を止める規則。 |
| Evidence over Self-Declaration | readiness を AI の自己申告ではなく、既存 evidence から導く原則。 |
| Cockpit Status | reviewer 向けの圧縮された状態表示。 |
| Gate | policy で明示された場合のみ有効になる停止規則。 |
